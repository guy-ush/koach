# יומן כח-ZONE

מעקב RM ואימונים: בק סקוואט, מיליטרי פרס, דדליפט, בנץ׳ פרס (ואפשר להוסיף תרגילים).

- תיעוד 1RM / 5RM עם תאריך, וגרף התקדמות לכל תרגיל
- תיעוד אימונים לפי ק״ג או לפי אחוז מה־RM שקיים לתרגיל
- הכל נשמר רק במכשיר (localStorage). עובד גם בלי אינטרנט אחרי הפתיחה הראשונה.
- גיבוי לקובץ, עותקים יומיים במכשיר, ייצוא CSV

התקנה: לפתוח את הקישור בטלפון ← "הוספה למסך הבית".

גיבוי אוטומטי לגוגל דרייב (לא חובה): להכניס OAuth Client ID ב־`config.js`.
